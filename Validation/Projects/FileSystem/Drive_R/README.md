# MDK-Middleware Validation

## File System RAM Drive Validation project

This is a skeleton validation project for testing the API and functionality of the **File System** Component using the RAM drive **R:**.

The project contains the common validation framework but does not yet define File System test cases. Executing it reports **No tests selected**.

For a description of how to build and run the validation, see the [validation documentation](../../../README.md#build-the-validation-project).
